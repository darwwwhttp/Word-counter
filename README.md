## 1. Описание плагина
**Word Counter** — расширение для Visual Studio Code, предназначенное для подсчёта количества слов и строк в открытом текстовом документе.

Основная задача инструмента — избавить пользователя от необходимости использовать сторонние сервисы для базовой аналитики текста, предоставляя всю необходимую статистику прямо внутри интерфейса редактора через удобную команду.

---

## 2. Возможности
Расширение разработано на языке TypeScript. 

* Подсчёт количества слов во всём открытом документе.
* Подсчёт количества строк в документе.
* Отображение результатов в информационном сообщении VS Code.

---

## 3. Использование
+ Откройте текстовый файл в Visual Studio Code.
+ Нажмте Ctrl + Shift + P, чтобы открыть палитру команд.
+ Выполните команду Word Counter: Count Text.
+ Результат отобразится в информационном сообщении.

---

## 4. Технологии
- TypeScript
- Visual Studio Code Extension API
- Node.js
